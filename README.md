# Elecciones 29N · Datos públicos

Feed público para la app Android **Elecciones 29N España**.

## Principios
- **Censo y electores:** INE / Oficina del Censo Electoral.
- **Resultados históricos:** Ministerio del Interior / Infoelectoral.
- **Intención de voto:** encuestas públicas agregadas con trazabilidad de casa demoscópica y fecha.
- **Proyección de escaños:** modelo derivado; no es un resultado oficial.
- **Veda:** desde el 24/11/2026 no se generan nuevas estimaciones de encuestas.
